# 管理界面规格（admin-ui）delta

## MODIFIED Requirements

### Requirement: 源管理界面

后台 MUST 提供源订阅管理界面。

- MUST 支持新建源（填写名称、URL、可选前缀）并在提交后展示探测结果（成功/失败、识别格式、节点数）
- MUST 支持编辑源的名称、URL、前缀、缓存有效期
- MUST 支持删除源，删除 MUST 有二次确认
- 源列表 MUST 展示每个源的名称、格式、健康状态（最近回源时间与结果）、绑定的 token 数
- 源列表 MUST 展示缓存中的订阅已用量（upload + download）/总量、到期时间与建议更新间隔；无合法元数据时显示“暂无”

#### Scenario: 新建源并看到探测结果

- **WHEN** 管理员填写源名称与 URL 提交创建
- **THEN** 界面显示探测结果：识别出的格式与节点数，或失败原因

#### Scenario: 删除源二次确认

- **WHEN** 管理员点击删除某源
- **THEN** 弹出确认提示；确认后源消失，取消则不执行删除

#### Scenario: 查看源用量与到期时间

- **WHEN** 源缓存包含订阅用量元数据
- **THEN** 源列表显示人类可读的“已用 / 总量”、到期时间与更新间隔

#### Scenario: 源未提供用量

- **WHEN** 源缓存没有合法订阅用量元数据
- **THEN** 源列表相应位置显示“暂无”，其余管理功能不受影响

新建/编辑源表单 SHALL 提供源类型选择：

- 「URL 订阅」：显示上游 URL 与缓存 TTL 字段（既有行为）
- 「手动节点」：显示多行文本框（每行一条分享链接），隐藏 URL 与 TTL 字段
- 类型切换即时显隐；编辑既有源时按其 kind 初始化
- 源列表的健康状态、格式、用量列对 static 源照常展示（用量为空）

#### Scenario: 创建手动节点源

- **WHEN** 管理员选择「手动节点」，粘贴 vless 与 hysteria2 分享链接后提交
- **THEN** 创建成功并展示探测结果（格式 base64、节点数），表单字段随类型正确显隐

#### Scenario: 表单控件主题和对齐

- **WHEN** 在桌面或窄屏打开手动节点源表单
- **THEN** 下拉框、文本框与普通输入框 MUST 采用一致的宽度、内边距、边框与暗色主题；多行文本框只能纵向缩放
- **AND** 切换类型时隐藏的输入项 MUST 禁用，不参与浏览器表单校验；可见必填项继续校验

#### Scenario: 编辑源类型后保存

- **WHEN** 管理员编辑源并切换类型、填入新类型必需数据并保存
- **THEN** 后端 MUST 持久化新类型，重新打开表单仍显示新类型与正确内容，token 绑定保持不变
