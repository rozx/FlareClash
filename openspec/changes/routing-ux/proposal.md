# 分流设置页交互改版

## Why
现有分流页按实现结构排版：先是「节点分组 · Clash」，再是每行重复「匹配条件/内容/动作」标签的规则表，预览、JSON、Hiddify 导出和大段兼容说明平铺在同一页，保存按钮在页面最底部。管理员最常做的事——「让某个网站走代理/直连/拦截」——需要先理解 Clash 规则类型、手动选类型、逐条添加，再滚到底保存；离开页面还会静默丢失草稿。

## What Changes
- 页面按任务重排：添加规则 → 规则列表（含兜底）→ 测试网址 → 节点组（可选，折叠）→ 备份与导出（高级，折叠）。
- 「添加规则」支持一次粘贴多个域名/IP 段（换行、逗号或空格分隔），默认自动识别类型；可粘贴完整网址（自动取域名）。新规则插到最前面优先生效，加入前先经服务端校验，逐项报错。
- 规则列表改为紧凑行：表头只出现一次，去向用颜色区分，内置常见规则（局域网、本机、中国大陆 IP）显示中文说明；兜底作为固定的最后一行「其他所有流量」。
- 「测试网址」接受完整网址，结果高亮命中的规则行。
- 有未保存修改时显示固定在底部的保存栏（保存 / 撤销修改）；站内切页或关闭页面前提示确认。
- 节点组隐藏内部 ID，显示被几条规则使用；JSON、Hiddify 导出与恢复默认收进「备份与导出」。

## 非目标
不改分流配置数据结构、API 与校验规则，不改 Clash/Hiddify 输出；不新增规则类型、远程规则集或规则模板（作为后续功能另议）。

## 影响
仅管理页前端（`public/admin/routing.js`、`app.js` 路由守卫、`style.css`）与浏览器测试。
